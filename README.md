# OPERATION CRIMSON

ブラウザで動作するタクティカル FPS。Three.js 製。
**テクスチャ・3Dモデル・レベル・効果音のすべてをコードから生成**しており、外部アセットを一切使用していません。

---

## 動かす

```bash
npm install
npm run dev        # 開発サーバ  http://localhost:5173
npm run build      # 本番ビルド → dist/
npm run preview    # ビルド結果の確認  http://localhost:4173
```

### Vercel へのデプロイ

リポジトリを Vercel に接続するだけで動きます（`vercel.json` を同梱）。

| 設定項目 | 値 |
|---|---|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |

静的サイトとして配信されるため、サーバサイドの処理は不要です。

## 操作

### キーボード / マウス

| キー | 動作 |
|---|---|
| `W` `A` `S` `D` | 移動 |
| `Shift` | スプリント（前進中のみ・スタミナ消費） |
| `Ctrl` / `C` | しゃがみ（スプリント中に押すとスライディング） |
| `X` | 伏せ |
| `Space` | ジャンプ／乗り越え（マントル） |
| `Q` / `E` | 左右へ体を傾ける（リーン） |
| 左クリック | 射撃 |
| 右クリック | 覗き込み（ADS） |
| `R` | リロード |
| `1` `2` / ホイール | 武器切り替え |
| `Tab` | スコアボード |
| `Esc` | 一時停止 |

### スマートフォン

画面左半分のドラッグで移動（大きく倒すと自動スプリント）、右半分のドラッグで視点移動。
射撃・照準・ジャンプ・しゃがみ・リロード・武器切替は画面上のボタンで操作します。
横画面推奨。セーフエリア（ノッチ・ホームインジケータ）を避けて配置されます。

## 設計の要点

### すべて手続き型生成

- **テクスチャ** — タイリング可能なノイズ（値ノイズ / Perlin / Worley / リッジド / 定義域歪み）から
  アルベド・ノーマル・ORM（AO/ラフネス/メタルネス）を実行時に合成。30種類以上。
- **武器モデル** — 面取り箱・押し出し断面・ロフトを組み合わせて構築。
  ピカティニーレール、フラッシュハイダー、湾曲マガジン等を部品化。
- **キャラクタ** — ボーン階層に部位メッシュを配置し、歩行・構え・発砲・死亡を
  手続き型アニメーションで表現（スキニング不使用）。
- **効果音** — WebAudio で合成。銃声は「撃発のトランジェント → 膨張するボディ →
  反響のテール」の 3 層構造。

### レンダリング

ACES トーンマッピング、PBR、GTAO、ブルーム、SMAA に加え、
自前の合成パスで色収差・ビネット・フィルムグレイン・シャープ化・
**スプリットトーン**（影に寒色／ハイライトに暖色）とバイブランスを適用。
暖色のキーライトと寒色のフィルライトを対比させることで色の分離を作っています。

### 物理

一様グリッドによるブロードフェーズ、円柱キャラクタの軸別衝突解決（段差乗り越え付き）、
スラブ法によるレイキャスト。薄板の貫通判定にも対応。

### AI

ナビメッシュを持たず、ステアリング + ひげレイによる障害物回避で移動します。
事前ベイクが不要なため、マップを追加してもそのまま機能します。
視野角と遮蔽判定による知覚、巡回／追跡／交戦／退避の状態機械、武器別の適正距離維持を実装。
